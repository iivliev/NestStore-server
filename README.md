# NestJS Shop

## Description

A NestJS-based e-commerce application with user authentication, product management, and more.

## Installation

```bash
$ npm install
```

## Environment Setup

Before running the app, configure your environment variables in `.env.development` for development and `.env.test` for testing.

## Running the app

```bash
# development
$ npm run dev

# production mode
$ npm run build
$ npm run start:prod
```

## Database

```bash
# start database
$ npm run db:dev:up

# stop database
$ npm run db:dev:down
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

```

## Documentation

```bash
# generate documentation
$ npm run doc

# watch documentation
$ npm run doc:watch
```

## API Documentation

Once the app is running, you can access the Swagger API documentation at `http://localhost:3001/api` (adjust the port as per your environment configuration).
